# M3 测试契约与当前验收

本变更实现受预算约束的配置校验、连通性、下载测速及测试历史。发布仍沿用 G2 的原子配置校验规则，网络测试结果不自动成为发布门槛。

## 接口与冻结

`POST /api/v1/tests` 使用 `Idempotency-Key`，最多选择 100 个节点或完整两跳链。离线配置校验不接受目标，`max_bytes` 必须为 0，也不解析 DNS。在线任务只接受登记目标 ID。目标登记检查管理员的授权声明、HTTP(S) URL、全部 DNS 答案和响应策略边界；`approved` 不表示已通过连通性测试。实际执行重新冻结批准 IP，保留 Host/SNI，禁止重定向及环境代理，HTTPS 验证证书。

一次事务冻结完整依赖及安全纪元、目标修订、锁定构建和有效限额，预留首次 attempt 预算，并创建全部子任务。相同请求的幂等重放返回原批次，不依赖新的 DNS 或当前对象修订，也不再次预留。相同键用于不同请求时返回冲突。

## 预算与执行

默认 UTC 日预算 1 GiB、连通性 4 并发、吞吐 1 并发，全局和本机同时检查。满槽类型不挡住其他类型的队首任务。预留记录按 attempt 唯一，结果接收、结算和终态同事务提交；跨日仍结算原预留桶。未执行取消释放额度；已执行的失败、取消保留已读取字节，失联未知用量按上限计入。

配置或节点失败不重试；连通性基础设施故障最多重试一次且重新预留，下载不自动重试。目标删除、停用、依赖安全撤销及构建停用会阻止新领取，并在心跳中取消活动任务。普通编辑保留冻结输入，结果按完整依赖标记历史。

Linux `RLIMIT_NPROC` 统计同一 UID 的线程总数。在线槽位共同使用 128 的线程上限，与部署容器 `pids_limit: 128` 配合，仍由 seccomp 禁止 fork、进程式 clone 和任意执行。离线配置任务保留 32 上限，与在线任务在同一 Runner 上互斥；在线连通性与下载槽位可并行。局部上限同时由 Runner 与数据库约束。

在线执行锁定回环端口，按内核的类型化文档绑定监听器，对最终执行字节再次真实校验并记录摘要。Mihomo 使用显式 TCP SOCKS listener，关闭 UDP；sing-box 仅获准必要的 `NETLINK_ROUTE` 通知能力，不获得网络管理 capability。文件、地址空间、CPU、进程与清理约束继续生效。部署侧 IP 出站规则及每次启动的就绪绑定已通过 amd64 分项验证，见 T-054。

## 结果语义与页面

连通性默认三个独立小响应样本，阶段 HTTP 耗时展示成功样本中位数；`sample_count` 为已尝试数，`failure_count` 为其中失败数。下载默认 10 秒或 20 MiB，达到任一上限立即停止应用读取；不足 1 秒或最低字节数不给出吞吐结论。纯文本出口 IP 响应最多 64 字节，只作诊断。独立 HEAD 健康检查只能把失败降为无法判断，不能证明代理成功。

历史包含完整依赖、目标修订、Runner 位置、实际执行配置摘要、有效限额和截断原因。执行期 CPU 限流是容器窗口观测，无法采集时缺省。失联终态保留历史，但不编造样本、耗时或位置。历史列表按完成时间和 ID 排序，`until` 排除端点，游标绑定全部筛选条件。

页面提供节点批量入口、节点和链的测试选择、目标登记、任务列表、批次与子任务取消以及历史筛选。SSE 断线或浏览器网络变化后先读持久快照，再按已消费序号续接；页面关闭只停止读取，不取消任务。

## 已验证范围

- 实库预算并发、事务回滚、幂等、跨日、重试、取消、失联下载、离线无 DNS、完整依赖历史、分页与 HTTP 契约：见 T-043 证据。
- Linux/amd64 三个锁定内核的合成 SOCKS 单节点和两跳、字节截断、断第一跳无绕行；真实 PostgreSQL 与 mTLS 队列；本机四个任务首次并发成功；真实取消 ≤5 秒：见 T-042 证据。
- 在线沙箱保留文件和进程隔离，限制监听/连接端口，拒绝 UDP、Unix socket 和非路由 Netlink：见 T-042 沙箱证据。
- 真实 Edge 浏览器完成批量测试、刷新恢复、实际 SSE 重连、取消不重复下载、移动端历史、键盘操作、中文 HTTP 目标登记及受保护地址拒绝：见 T-051 证据。

原生 arm64 暂无可用环境。用户提供的 `host-vps-scripts` 实际为 x86_64 且未安装 Docker；已确认保留 arm64 未验状态。arm64 仿真的既有文件沙箱检查失败，不计为通过，不提升任何客户端或组合支持状态。G3 尚未关闭。
