# ADR 0014：M1 编排闭环与回环控制预设

日期：2026-09-10。范围：T-020、T-021、T-022、T-029、T-049。

沿用资源目录与类型化 IR 实现路由、文本规则集、DNS 和审核预设，不新增原生配置编辑器。服务端持久化不可变加密修订和完整资源引用；编译器从冻结资源读取全部配置，不读取活动数据库、网络或当前时间。

规则数组保持语义顺序；浏览器文本仅转换为标准化 entries，并保存原始行号映射。DNS 引导和业务解析显式区分，域名解析规则不吞掉 CIDR 条目。目标策略覆盖独立于原始策略组，冻结时深复制，JSON 保留既有数组契约。

用户原先批准三个关闭控制 API 的 Linux 文件预设；实施核实该约束与运行时手动选路存在冲突。用户随后明确批准增设只监听回环地址的受控预设并进行真实验证。决定保留原三个预设，另增 sing-box 和 Mihomo 的固定回环控制变体；各变体有独立稳定 ID，初始化不覆盖既有预设。不存在原生等价实现或尚未执行验证的目标继续返回准确诊断，不能为关闭 G1 而伪造支持。

适配器版本设为 `0.2.0-m1-orchestration`，二进制构建身份不变，既有 G0 证据保留原适配器版本。T-008 为两个现有 GitHub Actions 检查启用主分支必需检查，外部配置回读见对应证据。

G1 关闭仍取决于全部适用验收结论；本 ADR 不替代真实内核、浏览器、实库或关卡评审。完整接口和验证边界见 `docs/m1-orchestration-contract.md`。

补充范围决定：真实内核证明 sing-box 1.14.0 的 IP 解析失败会终止连接，无法保持后续域名规则匹配。用户单独批准“接受 sing-box 此项限制并记录范围变更”。因此该目标的 resolve_for_ip_rules＋有效 IP 条件明确拒绝编译，不自动降级；preserve_domain 和其他两个内核的模式范围保留。失败反例、源码依据和批准历史见 G1 评审记录。
