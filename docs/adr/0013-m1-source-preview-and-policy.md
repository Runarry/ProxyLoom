# ADR 0013：来源预览闭环与策略组管理

日期：2026-09-09。范围：T-014／T-015／T-016 补齐、T-019 与 T-048；不关闭 G1。

## 决策

来源刷新复用既有加密导入批次、分页、七天保留与原子幂等提交。Worker 在一次成功刷新事务中保存快照、来源条目和候选；人工确认只读取已冻结输入，不重新抓取网络。来源批次的 actor 可以为空以支持周期刷新，真正提交仍要求管理员会话及审计。

最新上游基线与已确认基线分开保存。manual 刷新不得让随后的本地覆盖编辑意外应用尚未确认的上游变化。safe_updates 继续自动应用可靠匹配，预览保留自动应用标记；模糊建议必须显式决定且不能抢占其他来源绑定。

策略组采用现有资源目录、加密不可变修订和引用表，不新增独立策略存储框架。策略只允许具体 Node／Chain 成员；覆盖为纯类型化合并。管理可保存性不代表目标内核支持，实际映射留给 T-029。

资源导出新增标准 Base64 URI 列表。URI 编码须被已支持的解析方言完整还原，无法表达的字段带资源 ID 和字段路径拒绝；不静默丢失显式 false 或安全字段。

## 兼容与实施

追加 000011（策略资源约束）与 000012（来源预览及已确认基线）迁移；不改旧迁移。扩展已有 API DTO、生成前端类型及 sqlc 输出，维护精确契约变更声明。普通文本导入仍不接受 source_id 原文关联、来源修订或 bind 操作。

当前采用用户批准的工程窗口实施，T-017／T-018 的既有证据只覆盖链和通用展开，不外推为策略或界面已验收。专项证据与任务状态分别维护，能力目录仍保持原状态。
