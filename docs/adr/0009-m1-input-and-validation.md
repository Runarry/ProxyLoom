# ADR-0009：M1 节点输入与持久配置校验

日期：2026-09-08。状态：用户批准实施，验收状态以逐任务证据为准。

## 决策

本窗口实施 T-009、T-010、T-011、T-039、T-041、T-047，以及 T-048 的节点／本地导入切片。T-006 的既有身份实现复用；T-008 远端强制检查仍需独立证据。整个 T-048、G1 和完整 P0 均不能据本窗口自动完成。

节点服务复用资源不可变修订、稳定 ID、目录锁、加密及认证；节点克隆在服务端根据 If-Match 检查源修订后创建新 ID，避免为复制向浏览器回显认证信息。安全停用、删除及认证变化保持既有 security_epoch 语义。

导入预览持久化原文和任务，并由 API Worker 解析。T-010 的直接依赖补入 T-011、T-039；不再将异步导入实现为请求进程中的临时 goroutine。候选每页最多 200 条，确认最多 5,000 条且同事务提交。客户端不能提交未读取或其他批次的候选。原始输入和未提交候选保留七天，到期明确显示 expired。

连接内容 HMAC 与包含资源 ID／修订的存储内容摘要分开。它仅作重复提示，不确认来源身份；来源绑定、周期刷新及人工覆盖仍属于 T-012～T-015。未知导入元数据只保存在加密候选内，不进入 Node 执行字段。

API Worker 和 Runner 共用持久任务事实，按 executor/type 严格隔离。Runner 共享协议包只含类型和纯验证，不引入数据库、全局密钥或管理会话依赖。默认租约 30 秒、心跳 5 秒；重复执行通过 fencing 和结果幂等限制副作用，不宣称 exactly-once。

本窗口 Runner 只执行 config_validate，校验原生错误不重试，基础设施错误最多自动重试一次。quota_reservation_id 仅对网络任务强制；配置校验字节结算为零，但并发、时间、内存、进程和禁网边界仍须生效。生产网络测试与预算实现留给 T-042～T-045。

## 验证与兼容

追加迁移，禁止改写 000001～000004。OpenAPI、生成类型、路由清单、夹具和精确契约摘要一起更新。真实 PostgreSQL 验证原子导入、并发修订和租约，真实 mTLS／锁定内核验证配置正负例，浏览器连接真实 API 验证节点与导入流程。

编译器支持范围继续依据已验证组合；六类节点可解析和保存不代表三内核全组合可以发布。能力保持 unverified。本窗口不提供订阅发布或网络测速入口。
