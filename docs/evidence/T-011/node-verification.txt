- Real management session setup, cookie authentication, CSRF and Origin validation.
- Foreign bearer credentials and cross-scope resource/history requests rejected.
- List/search uses literal case-insensitive name substring, protocol, tag, enabled filters and signed pagination.

- History/reference cursors preserve int64 precision, ordering tuples, scope and filter bindings; tampering is rejected.

Found and fixed during verification:
The original new audit actor foreign key inverted identity's user-then-scope locking against catalog's scope-then-user locking.
It could make concurrent authenticated edits fail instead of returning the expected CAS outcome.
Migration 000007 now uses a non-locking scoped actor membership trigger, valid because user IDs/scopes are immutable and hard deletion is forbidden.
A deterministic acceptance test holds the identity administrator lock while the catalog transaction writes its audit.
