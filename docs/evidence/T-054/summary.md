已验证：干净初始化、追加迁移、非 root 常驻进程、无数据库/Runner 公开端口、API 仅回环暴露、镜像内三个真实内核配置校验、Runner 私网端口拒绝与 mTLS 9091 例外、重建后启动随机标识变化及旧就绪记录拒绝、三服务重启后数据保留、真实加密备份及校验、同 Schema 升级/回退命令、独立新库恢复、旧会话和旧监控令牌失效、恢复后含凭证节点再次通过三内核校验。合成小数据集从恢复开始到服务校验完成为 **19 秒**，不能外推规模性能。

隔离验收主机自身需要 privileged 运行嵌套 Docker；这仅用于测试。产品 Compose 不挂载 Docker socket，不配置 privileged，不需要 TUN，Runner 不持有 NET_ADMIN。网络规则由 Linux 主机在指定 Runner 网络命名空间内设置。

验收发现并修复：Docker 存储后端对本地镜像 ID 的差异、BusyBox realpath 参数差异、Linux 重用网络命名空间编号导致旧就绪记录可能被接受，以及新部署库所有权与恢复权限不一致。失败轮次保留在 `.cache/deployment/`，没有改写为通过。
