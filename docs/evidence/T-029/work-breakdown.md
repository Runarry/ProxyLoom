# T-029 可验收子项

本拆分落实 `docs/PLAN.md` §4／§6 对 T-029 的要求。子项继承父任务的范围和依赖，工作量计入原 7–11 人日估算，不新增预算；实际人日未采集。子项不能以 `unsupported` 替代承诺范围或据此直接关闭 G1。

| 子项 | 估算 | 交付与验收 |
| --- | --- | --- |
| T-029.1 公共规范化与能力检查 | 1–2 人日 | 冻结根、深复制、完整资源闭包、确定性 Plan、目标覆盖、逻辑匹配、组专属最终出口标签、展开及产物上限；正负单元与确定性测试。 |
| T-029.2 Xray | 1–2 人日 | 候选协议、路由与 DNS 的 Xray 独立映射；原生轮询及不能等价映射字段的明确诊断；对应 Golden、锁定 linux/amd64 正反配置检查。 |
| T-029.3 sing-box | 1–2 人日 | 独立节点／链、路由、DNS 与受控手动选择；round_robin 明确拒绝；对应 Golden、锁定 linux/amd64 检查及控制切换证据。 |
| T-029.4 Mihomo | 2–3 人日 | YAML 稳定输出、路由／DNS、策略与受控手动选择；不注入公共健康检查或下载；对应 Golden、锁定 linux/amd64 检查及控制切换证据。 |
| T-029.5 全矩阵与 G1 汇总 | 2 人日 | 每个候选组合对应正反测试结论，构建／适配器／夹具与源码摘要可追溯；策略隔离与全故障无直连、适用 AC-01～12、T-041 和前置评审逐项核对。 |

原三个 Linux 文件预设保持关闭控制 API。用户于 2026-09-10 批准的 sing-box／Mihomo 回环控制变体单独验收，不外推 Xray、桌面／移动客户端或 arm64。

最终结果以本目录实际运行报告和阶段退出记录为准。本文件仅为拆分，不表示任何子项已经通过。
