# M3 / G3 逐项验收记录

日期：2026-09-14。基点 `246b08b` 的 M3 工作树；本记录为 AI 辅助工程验收，不冒充人工签字。仅交付本地自托管候选包，不创建公开版本或进行生产部署。

**当前结论：G3 保持打开。** M3 已完成 8 项功能工程验收；规定持续时间的容量、规模恢复、amd64 安装升级、源码质量、三内核与发布回归通过，候选交付包已实际组装。其余 6 项保留实施中：arm64 按用户决定运行未验，实际每日备份触发与持续健康、剩余镜像告警适用性和一项缺失的上游许可文本尚未闭合，不能标记 v1.0 完成。

表中“通过”仅覆盖本次 P0 与 G1/G2 已批准范围，不包括同一 FR 中的 P1 子项。sing-box IP 解析语义限制、未验客户端和未验协议互通组合保持原状态。证据代号均可在文末定位到具体文件；既有阶段记录不会被新结果覆盖。
