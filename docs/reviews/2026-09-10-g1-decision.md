## 已批准的目标限制：sing-box 按 IP 规则解析时的 DNS 失败语义

锁定 sing-box 1.14.0 的原生 `resolve` 动作在 DNS 查找失败时终止连接，且不存在继续匹配／忽略错误选项；原生 CIDR matcher 只匹配已有地址，不自动查询。真实反例中，IP 条件没有命中，后面的域名规则本应通过指定代理处理该域名：Xray／Mihomo 成功，sing-box 终止连接。

已排除“仅调整解析位置”的修复：把解析移到第一条 IP 规则前可修复更早域名规则被抢先解析，但不能修复 IP 规则之后的域名命中。不能通过全局提前解析、替换解析模式、调整路由顺序或自动直连宣称等价。

当前安全行为是让 sing-box 的 `resolve_for_ip_rules`＋有效 IP 条件组合明确编译失败（包括引用规则集中的 CIDR），携带路由资源 ID、`/payload/domain_resolution_mode` 和 target。`preserve_domain`、禁用的 IP 规则及不含 IP 条件的方案不受影响。Xray／Mihomo 的两种模式仍按真实测试实现。具体源码依据、修复前反例和最终测试见 [IP 路由证据](../evidence/T-029/native-ip-routing.md)。

此拒绝避免输出错误配置。范围调整依据本次用户明确批准，而非实现方自动缩减承诺。

## 用户范围决定与历史

曾向用户提出以下选择，并在保留失败证据的同时等待决定：

1. 保持原承诺范围：G1 继续开放，后续另行评估可保持相同语义的锁定内核版本或实现方案。

用户此前批准的是“增设回环控制预设并验证”，只适用于手动选择控制通道，不能外推为已批准本次 DNS／IP 路由范围变化。

用户随后单独回复：**“接受 sing-box 此项限制并记录范围变更”**。据此采用第二项：sing-box 1.14.0 不开放 resolve_for_ip_rules 与有效 IP 条件的组合；保留 preserve_domain，无 IP 条件时也不强制解析。Xray／Mihomo 的模式范围不缩减。该目标限制纳入本次 G1 验收范围，原始 FR／AC 编号保持不变；今后解除限制须新建可追溯构建／适配器验证，不直接修改旧证据。
