# 本地开发秘密

在仓库根执行 `pwsh -File scripts/dev-init.ps1` 显式生成到 `local/` 子目录。启动服务不会生成或替换秘密；再次运行初始化只校验已有文件，不轮换数据库密码。

这里的文件只用于本地开发，已被 Git 和 Docker 构建上下文排除。不要复制生产凭证。目录在 Unix 下为 0700；文件为 0444，方便非 root 容器读取绑定的文件，主机其他用户仍不能穿过目录。Windows ACL 授当前用户、SYSTEM、Administrators 完全控制；沙箱用户与仓库所有者不同时，额外授仓库所有者只读权限，供其 Docker Desktop 读取。

已有数据库卷与密码文件必须成套保留。不要删除密码后继续使用旧卷；数据库、密钥恢复与生产 secret 管理由后续 T-054/T-056 完善。
